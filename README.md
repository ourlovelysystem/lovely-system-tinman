# Tinman

Tinman is the voice-first listening surface for Our Lovely System.

The landing page opens as a seized, rusty mechanism. The ordinary pointer is replaced by an oil can. A visitor must oil three dry bearings before the page reloads into the clean metallic interface.

## Routes

- `/` — opening ritual and message browser landing surface
- `/appeals/` — appeal-mode recording control (next increment)
- `/accolades/` — reserved future behavior; no separate application or codebase

The route selects message behavior and tagging. It does not imply separate deployments.
